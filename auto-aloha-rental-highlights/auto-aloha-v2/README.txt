PUBLISH WITH GITHUB PAGES
1. Create a GitHub repository and upload the contents of the auto-aloha-v2 folder (index.html, style.css, app.js, assets/ and this README).
2. In the repository, open Settings → Pages.
3. Under Build and deployment, choose Deploy from a branch, select the main branch and / (root), then Save.
4. Wait for the Pages deployment to finish; GitHub will display the public website URL in Settings → Pages.

Google Fonts require an internet connection. All new vehicle images are included locally in assets/. Verify all business claims and final rental terms before publishing.
